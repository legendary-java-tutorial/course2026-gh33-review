# Угадай число

Тема игры: Лес.

## Режимы

| режим | числа | подсказки | победа |
|---|---|---|---|
| classic | 1–100 | больше / меньше | угадал! |
| трудный | 1–5000 | больше / меньше | угадал! |
| хардкор | 1–1000 | холодно — бери больше / горячо — бери меньше | угадал! |

## Запуск

`npm start` — партия, `npm test` — тесты.
